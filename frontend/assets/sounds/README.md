# Nexus interface sounds

Six original, mono 44.1 kHz / 16-bit PCM chimes, each 160–240 ms. Generated by
`scripts/generate_ui_sounds.py` with sine tones and smooth envelopes; no recording,
third-party sample or personal audio. Nexus-authored assets use the repository's
MIT license. Dependencies retain their separate licenses.

Sounds are optional and default to off. No hover or streaming-chunk sounds.
`frontend.sound_feedback.SoundFeedback` bounds volume and throttles rapid events.
Only these six named WAV assets are exempted from the private-recording exclusion.
