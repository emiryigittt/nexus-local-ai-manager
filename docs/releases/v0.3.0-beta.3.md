# Nexus 0.3.0 Beta 3 · Windows installer

## English

Maintenance beta for the Windows installer. Download **NexusSetup.exe**, run it and
open Nexus from Start. Python and a terminal are not required. Windows 10/11 x64 is
the target. Start Ollama, LM Studio or llama.cpp, load a model and use the
three-step connection wizard.

- One UI catalog now drives the desktop language: history, memory, About, clipboard
  consent, image and clipboard prompts, voice status, tooltips, tray menu and error
  messages follow **Settings → General → Language**. Answers, saved memory text and
  user input are never translated.
- The first-run wizard, the introduction and local speech setup keep their own
  bilingual copy; provider, model, voice and command identifiers stay untranslated.
- Stopping the local API also stops the MCP servers it started, so a clean exit no
  longer leaves helper processes such as `node`/`npx` running. A hard stop is covered
  by the launcher's Windows job object.
- An MCP server that writes a lot to stderr no longer stalls its own session, and a
  request that times out now reports what that server last printed.
- An older conversation now opens from the history list or a saved memory source link
  instead of failing with "not found": the record is read directly by its id rather
  than searched inside the most recent 500 conversations.
- Combined Windows application distributed under **GNU GPL v3**. Nexus-authored
  source retains MIT; original dependency notices are preserved.
- Complete Nexus source, corresponding dependency source archives, exact build
  inputs, license texts, native configuration and SHA-256 checksums are supplied.

**Unsigned beta:** Windows may show a publisher warning. Verify SHA256SUMS.txt.
Wake detection remains experimental; use F2 for manual speech capture. Hardware
microphone quality and real model performance are not verified by the synthetic checks.
LLM, Whisper and Supertonic model weights are separate downloads. Cloud speech
requires consent. Uninstall preserves `%LOCALAPPDATA%\Nexus` user data.

Assets: NexusSetup.exe, Nexus-source.zip, Nexus-dependency-sources.zip,
dependency-sources.json, windows-package-check.json, release-manifest.json,
SHA256SUMS.txt. Download the sources as well if modifying or redistributing.

## Türkçe

Windows kurulum paketi için bakım betası. **NexusSetup.exe** dosyasını indir,
çalıştır ve Başlat menüsünden Nexus'u aç. Python veya terminal gerekmez. Hedef
Windows 10/11 x64'tür. Ollama, LM Studio veya llama.cpp'yi açıp model yükle;
üç adımlı bağlantı sihirbazını kullan.

- Masaüstü dili artık tek bir arayüz kataloğundan geliyor: geçmiş, hafıza, hakkında,
  pano izni, görsel ve pano istemleri, ses durumu, ipuçları, sistem tepsisi menüsü ve
  hata mesajları **Ayarlar → Genel → Dil** seçimini izler. Yanıtlar, kayıtlı hafıza
  metinleri ve kullanıcı girdisi hiçbir zaman çevrilmez.
- Karşılama sihirbazı, tanışma ve yerel ses kurulumu kendi çift dilli metinlerini
  kullanır; sağlayıcı, model, ses ve komut kimlikleri çevrilmez.
- Yerel API durdurulduğunda başlattığı MCP sunucuları da durur; temiz çıkışta
  `node`/`npx` gibi yardımcı süreçler arka planda kalmaz. Zorla kapatma, başlatıcının
  Windows job nesnesiyle kapsanır.
- Çok sayıda stderr yazan bir MCP sunucusu artık kendi oturumunu kilitlemez ve
  zaman aşımına uğrayan bir istek o sunucunun son çıktısını bildirir.
- Eski bir sohbet artık geçmiş listesinden veya kayıtlı bir hafıza bağlantısından
  "bulunamadı" hatası almadan açılır; kayıt son 500 sohbetin arasında aranmak yerine
  doğrudan kimliğiyle okunur.
- Birleşik Windows uygulaması **GNU GPL v3** kapsamında dağıtılır. Nexus'un kendi
  kaynağı MIT olarak kalır; bağımlılıkların özgün bildirimleri korunur.
- Tam Nexus kaynağı, eşleşen bağımlılık kaynakları, sabitlenmiş derleme girdileri,
  lisans metinleri, yerel yapılandırma ve SHA-256 değerleri sunulur.

**İmzasız beta:** Windows yayıncı uyarısı gösterebilir; SHA256SUMS.txt ile doğrula.
Hey Nexus deneysel kalır; elle ses girişi için F2 kullanılabilir. Fiziksel mikrofon
kalitesi ve gerçek model performansı yapay testlerle doğrulanmaz. LLM, Whisper
ve Supertonic ağırlıkları ayrıca indirilir. Bulut ses için onay gerekir.
Kaldırma `%LOCALAPPDATA%\Nexus` kullanıcı verilerini korur.

Dosyalar: NexusSetup.exe, Nexus-source.zip, Nexus-dependency-sources.zip,
dependency-sources.json, windows-package-check.json, release-manifest.json,
SHA256SUMS.txt. Değiştirme veya yeniden dağıtım için kaynakları da indirin.
