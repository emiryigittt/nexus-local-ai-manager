# Nexus 0.3.0 Beta 1

A small local AI companion at the top of your Windows screen.
Connect your own Ollama, LM Studio or llama.cpp model, work with documents,
and decide what Nexus remembers.

**Public source beta · Windows 10/11 x64 · English / Türkçe**

## Try it

1. Install 64-bit Python **3.11, 3.12 or 3.13** and start a local model server
   with a loaded model. Nexus does not include or install an LLM.
2. Download **Source code (zip)** below and extract it completely.
3. Double-click **Nexus Baslat.bat**. It creates the environment and installs
   the dependencies; the first preparation needs internet access.
4. Choose a language, test your model connection, then try the sample document.
   **Alt + Space** opens chat; **F2** starts voice input after speech setup.

## What is new

- A compact top-edge strip, hover tools and expandable chat.
- RGB accents, optional rainbow animation, bot/cat companions and original chimes.
- An optional introduction and memory cards you can inspect, approve, edit or forget.
- Automatic finish after a configurable speech pause and optional transcript review.
- Balanced local transcription by default, with an optional larger model.
- Smoother streamed answers and captions that follow speech playback. Local
  word timing is approximate.

## Beta limits

This release distributes **source code**, not a Windows installer. The unsigned
installer remains a local development preview while the PyQt/Qt distribution
licensing decision and dependency review are open. Nexus-authored source remains
MIT; dependency and model terms remain separate.

Hey Nexus is experimental and can miss a trigger; use F2 as a fallback. Physical
microphone accuracy, real-model end-to-end quality and clean-PC installation still
need broader user testing. Python 3.14 is not recommended for this beta because
of earlier intermittent native test crashes. Some UI messages remain partly Turkish.

Keep the unauthenticated API on **127.0.0.1**. Local chat uses your configured model
endpoint; optional web tools and cloud speech have separate permissions and network
boundaries. Nexus does not encrypt its local database.

The local prepublication suite passed 377 tests, Ruff and 13 packaged smoke checks.
The smoke checks used a synthetic model server; they do not establish model or
microphone quality. Publication is gated on Windows CI for Python 3.11–3.13.

isteğe bağlı ses ve kontrolü sende olan hafıza sunar.

hata/özellik bağlantılarından paylaş; özel dosya, veritabanı, ses kaydı veya anahtar ekleme.
