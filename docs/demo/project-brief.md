# Aurora — synthetic project brief / örnek proje belgesi

This is fictional demo content. It contains no real customer, credential, or private project data.
Bu belge yalnızca Nexus'un belge okuma özelliğini denemek için hazırlanmıştır.

## Goal / Amaç

Aurora is a small desktop reading-list prototype. The team wants a usable preview,
not a feature-complete release. Aurora küçük bir masaüstü okuma listesi prototipidir.

## Three release priorities / Üç yayın önceliği

1. **Reliable saving / Güvenilir kayıt:** a saved reading item must remain after restart.
2. **Keyboard access / Klavye erişimi:** adding, finding and opening an item must work without a mouse.
3. **Clear offline state / Açık çevrimdışı durumu:** show when a page cannot be fetched; preserve saved notes.

## Out of scope / Kapsam dışı

Cloud sync, paid accounts, mobile applications, and an installer are not part of this preview.
Bulut eşitleme, ücretli hesaplar, mobil uygulamalar ve kurulum paketi bu önizlemede yoktur.

## Acceptance / Kabul

Save a synthetic item, restart, reopen it, and navigate with the keyboard. Disconnect
the network and confirm that notes remain readable and fetch failure is explained.
